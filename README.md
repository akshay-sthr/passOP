# PassOP — Password Manager

PassOP is a password manager web application that helps users store and manage their website credentials in one place.

I built this project to improve my understanding of React, frontend development, and managing application data.

## Features

- Save website URLs, usernames, and passwords
- View saved credentials
- Edit existing entries
- Delete credentials when they are no longer needed
- Simple interface for managing passwords

## Tech Stack

- React.js
- JavaScript
- HTML
- Tailwind CSS
- Vite

## Getting Started

### Clone the repository

```bash
git clone https://github.com/akshay-sthr/passOP.git
```

### Navigate to the project folder

```bash
cd passOP
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to use the application.

## How It Works

Users can add website details and their associated login credentials through the interface. They can then view, update, or delete saved entries.

The storage method depends on the implementation. If the application uses browser `localStorage`, the data is stored in that browser. If it uses a backend and database, the credentials are handled by that system instead.
